# Итерация 3: пересадка знаний — «Ткань-Т»

> Облачный контейнер, 4 CPU. Ядро-донор — Qwen3-0.6B (Apache-2.0), **заморожено**.
> Обучались только новые органы тела: 1 час «глаз», 1 час «голос».

## Устройство

```
голые байты → [ГЛАЗ: байты + хеш-n-граммы → 4 причинных свёрточных блока]
            → [ГОЛОВА ГРАНИЦ: где кончается кусок (видит 1 байт вперёд)]
            → векторы кусков → [ЯДРО: 28 слоёв Qwen3-0.6B, заморожено]
            → мысль → [ГОЛОС: маленький трансформер: мысль → байты следующего куска + «конец куска»]
            → голые байты
```

Токенайзер учителя нужен только как учебное пособие на этапе 1: он показывает, где учитель резал текст. В работе «Ткань-Т» читает и пишет байты.

## Этап 1б: голос (60 минут CPU)

Учился выговаривать мысль ядра байтами. Итог: 0.8–1.6 бит/байт при «правильных» мыслях.

## Язык: бит на байт (меньше — лучше)

| | wiki RU | wiki EN | код |
|---|---|---|---|
| Qwen3-0.6B со своим токенайзером (учитель) | 1.16 | 1.43 | 1.09 |
| наш глаз → ядро Qwen (выход учителя) | 1.40 | 1.75 | 1.47 |
| **весь организм: глаз → ядро → голос** | 1.81 | 2.56 | 2.27 |
| «Ткань D» (6.9M, своё ядро) | 1.73 | 2.72 | 4.20 |

Глаз работает: ядро понимает прочитанное по байтам, хотя и с потерей 0.25–0.38 бит/байт.

Голос — слабое звено. Он учился на мыслях ядра, которое читало через *настоящий* токенайзер, а в работе получает мысли ядра, читавшего через наш глаз.

## Экзамен (3 примера формата, как у эталона)

| домен | Ткань-Т RU / EN | Qwen3-0.6B RU / EN |
|---|---|---|
| math | 98% / 100% | 98% / 100% |
| word | **70%** / 58% | 68% / 62% |
| order | 30% / 26% | 66% / 34% |
| seq | 47% / 44% | 53% / 47% |
| code | 77% / 68% | 94% / 90% |
| trace | 40% / 40% | 42% / 40% |
| **итого** | **59.5% / 55.5%** | **69.0% / 60.6%** |

**Организм на голых байтах сохраняет 86% (RU) и 92% (EN) умений донора** после всего 2 часов обучения тела на CPU.

Потери пока в коде и логике. Калибровка не настроена: организм всегда «уверен» (ECE 0.43) — самомодель к нему ещё не подключена.

Без примеров формата («Вопрос: Какая столица России?») организм пока отвечает пустотой, а свободные продолжения зацикливаются. Голосу нужен этап 2.

## Что дальше (этап 2, нужна GPU — Colab)

1. Голос учится на мыслях ядра, читавшего **через наш глаз**: убираем сдвиг.
2. Глаз учится **через ядро** (градиент через замороженное ядро по ошибке следующего куска), а не только подражанием входным векторам.
3. Свободная нарезка: голова границ отпускается от учительской разметки.
4. «Руки», память, самомодель и цикл саморазвития — на «Ткани-Т». Теперь у модели есть база: язык и трудные задачи, которые хотя бы изредка решаются. Без неё цикл саморазвития не может вырастить новое (см. итерацию 2).
