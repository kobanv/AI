### Главная находка: привычка верная, а «зрение» неточное

C на каждую задачу пишет программу и правильно читает результат исполнения. Но числа из условия она переписывает с ошибками:

```
Сколько будет 23 + 97?    → <py>print(32 + 97)</py><out>129</out> 129
Сколько будет 334 - 253?  → <py>print(343 - 351)</py><out>105</out> 105
Сколько будет 61 * 18?    → <py>print(61 * 9)</py>   (уровень 5 не тренировался: «тянет» шаблон 2×1)
x = 2; y = x * 2 - 7      → <py>x = 4\ny = x * 9 - 3 ...</py>
```

Причина в архитектуре. Байтовый декодер видит лишь ~22 соседних байта, а до условия дотягивается только через сжатые чанки, где точные цифры теряются.

**Исправление (модель D):** слой внимания по байтам в декодере — окно 256 байт, «точный взгляд» назад.

### Рекурсия: снова не используется

bpb и экзамен R/C одинаковы при r = 2…16 (до 5-го знака). Случайное начальное состояние лишь научило модель игнорировать мысль: шум проще всего не замечать.

**Исправление (модель D):** мысль подмешивается сложением (`s ← s + e`), а не через адаптер. Обойти её так нельзя.

## Цикл саморазвития (`tkan/selfimprove.py`)

В цикле **нет ответов учителя**:
- **мир** ставит задачи и говорит «верно/неверно»;
- **модель** сама:
  - строит карту навыков;
  - выбирает фокус: «почти получается», «растёт», «следующий шаг после освоенного»;
  - пробует решить, жадно и с температурой;
  - учится во «сне» только на решениях, прошедших проверку;
  - ведёт дневник.

Экзаменационные задачи для практики закрыты. Навык code/5 закрыт целиком: все его задачи ушли на экзамен.
