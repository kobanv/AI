# Ткань

Исследовательский проект: ИИ-собеседник, помощник и агент новой архитектуры, который запускается на одной RTX 5070 Ti (16 ГБ) или на CPU.
Он работает на голых байтах, думает рекуррентным ядром, хранит знания в растущей памяти, знает свои возможности и учится всю жизнь.

- `docs/00_ANALYSIS.md` — анализ, расчёты, архитектура v0, гипотезы и план итераций
- `tools/budget.py` — воспроизводимый расчёт бюджета вычислений и памяти (`python tools/budget.py`)
